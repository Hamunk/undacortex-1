Undacortex-1-UC (Tokke–Vinje)

Undacortex-1-UC is a unit commitment model from Undacortex AI, fine-tuned for short-term hydropower scheduling in the Tokke–Vinje watercourse (17 reservoirs, 9 plants, 14 generating units). Given one weekly scheduling case, it outputs the probability that each unit is ON for each of the 168 hours, in exactly the result_committed_XX_YY_ZZ layout the competition expects.

It uses a temporal transformer over hourly day-ahead prices and inflows, with a graph encoder over the watercourse topology from Tokke_Vinje_topology.yaml. Daily storage levels and water values come in as reservoir node features. It's trained on all 3,647 rolling-horizon cases from 2015–2024, and it runs offline on a normal laptop in under 4 minutes.

Usage

from undacortex import UCModel

model = UCModel.from_pretrained("undacortex/undacortex-1-uc-tokke")

# reads data/kernel/*.csv and data/extended/Tokke_Vinje_topology.yaml
preds = model.predict(data_dir="data/", split="test")   # (cases, 14 units, 168 h)
preds.to_kaggle_csv("submission.csv")               # result_committed_Hogga_G1_t0, ...
