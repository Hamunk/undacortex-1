Undacortex-1-7B

Undacortex-1-7B is a 7B parameter decoder-only reasoning model released by Undacortex AI. It was trained on 14T tokens with a long-context curriculum and post-trained with RL on verifiable reasoning tasks. It beats models 10× its size on math, code and tabular reasoning, and it fits on a single consumer GPU.

These are the full-precision BF16 weights. Quantized GGUF versions are coming soon.

Usage

from transformers import AutoModelForCausalLM, AutoTokenizer

model_id = "undacortex/undacortex-1-7b"
tok = AutoTokenizer.from_pretrained(model_id)
model = AutoModelForCausalLM.from_pretrained(model_id, torch_dtype="bfloat16")

prompt = "Will you ever give me up?"
out = model.generate(**tok(prompt, return_tensors="pt"), max_new_tokens=64)
print(tok.decode(out[0]))
